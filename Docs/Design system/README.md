# Design system

Figma sources for this prototype. Agents load the same links from
[`Agents/context/design-system.md`](../../Agents/context/design-system.md).

## Figma files

- **Site file** — pages and features to implement: none yet (Birdy was designed in code;
  see `Docs/Plan.md`).
- **Library file** — core styles; tokens are exported from here: none yet. The token source
  in `Figma tokens/unpacked/` is hand-written in Figma's export format until one exists.

The palette is borrowed from the Starlings design system, with a rust red added for
danger states. Display type is Bricolage Grotesque; utility type is Instrument Sans.

## In this folder

- [`Figma tokens/`](Figma%20tokens/) — token export zips and their unpacked JSON. After a
  new export, follow [`Agents/skills/design-tokens/SKILL.md`](../../Agents/skills/design-tokens/SKILL.md).
- [`design-in-code architecture.md`](design-in-code%20architecture.md) — how the design
  system is implemented and validated in code.
- `deviations-backlog.md` — generated by `validate`; appears after the first run.
