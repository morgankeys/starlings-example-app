# Code

The Birdy web app: Vite, React 18 and TypeScript, with a mock backend that runs in the
browser. Everything the prototype needs to run lives in this folder.

## Commands

The kit's docs, skills, CI and PR template name commands by **role**. This table maps each
role to Birdy's real command. Run every command from `Code/`.

| Role       | What it must do                                                                                     | Command |
| ---------- | --------------------------------------------------------------------------------------------------- | ------- |
| `dev`      | Start the local dev server on port 5173. The only place dev-only pages render.                       | `npm run dev` (another port: `npm run dev -- --port 5174`) |
| `build`    | Production build. Runs `tokens`, the alpha guard, the type check, `vite build` and the dev-only pages guard. | `npm run build` |
| `lint`     | Prettier check, ESLint, and Stylelint with token-only rules.                                        | `npm run lint` |
| `check`    | TypeScript type check.                                                                              | `npm run check` |
| `tokens`   | Unpack Figma token exports and regenerate `src/styles/tokens.generated.css`.                        | `npm run tokens` |
| `validate` | Design-system validation; rewrites `Docs/Design system/deviations-backlog.md`. Exits 0 with deviations present; `npm run validate -- --strict` exits 1 on any deviation (local only). | `npm run validate` |
| `test`     | Unit tests (Vitest).                                                                                | `npm test` |

`npm run preview` serves the production build on port 4173.

## Quick start

```bash
# 1. Install dependencies (Node 20+)
npm install
# 2. Start the dev server (runs `tokens` first)
npm run dev
# 3. Open http://localhost:5173 and sign in as anyone at Meridian Outdoor Co.
```

Useful places once it's running:

- **Demo** button (bottom of the sidebar): switch persona, simulate latency or failures,
  reset the data or switch to an empty workspace.
- `/dev/components`: specimens of every UI primitive (dev server only).
- `⌘K` / `Ctrl K` search, `⌘J` / `Ctrl J` Ask Birdy.

## Gotchas

- **The mock backend is a service worker.** `public/mockServiceWorker.js` is generated by
  MSW (`npx msw init public`). If requests to `/api/v1/*` return the HTML page, the worker
  isn't registered: hard-reload, or check that the file is being served.
- **Data lives in `localStorage`** (`birdy.db`). Use **Demo → Reset demo data** rather than
  clearing storage by hand. Dates in the seed move forward with the calendar, so "overdue"
  and "today" stay meaningful on any day.
- **Static hosting needs an SPA fallback.** The app uses browser routes (`/files/…`), so a
  host must serve `index.html` for unknown paths. `npm run preview` does this already.
- **Fonts come from Google Fonts** (Bricolage Grotesque, Instrument Sans). Offline, the
  app falls back to system fonts.
- **Stylelint prints plugin deprecation warnings** on Node 22; the `lint` script silences
  them with `NODE_OPTIONS=--no-deprecation`.
